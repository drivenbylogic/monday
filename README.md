# Monday - Personal Assistant

Monday is a highly modular personal assistant backend that turns your life's tasks, events, obligations, and information into a focused daily brief. Built as a comprehensive Java Spring Boot application, it acts as a central nervous system for your personal life.

## Features & Modules

Monday is composed of several independent but interconnected modules:

1. **Projects Module**: Manage long-term goals, milestones, and tasks. Features a task execution queue and velocity tracking.
2. **Events Module**: Keep track of schedules, appointments, and daily routines, with automated preparation tracking.
3. **Finance Module**: Maintain budgets, track transactions, calculate safe-to-spend metrics, and manage subscriptions.
4. **Vehicles Module**: Track telemetry, log maintenance and fuel, and manage insurance renewals for your vehicles.
5. **Administration Module**: Manage legal obligations, taxes, secure vault documents, and physical archives.
6. **Intelligence Module**: Aggregate information feeds (RSS) and classify/summarize articles using an AI Gateway for your morning briefing.

## Tech Stack

- **Framework**: Java 21 & Spring Boot 3.4
- **Database**: PostgreSQL 17
- **Database Migrations**: Flyway
- **Security**: Spring Security & JWT Authentication
- **Documentation**: OpenAPI (Swagger UI)
- **Containerization**: Docker & Docker Compose

## Getting Started

### Prerequisites

- [Docker](https://www.docker.com/) and Docker Compose
- Or, for local development: Java 21+, Maven 3.9+, and a local PostgreSQL instance.

### Running with Docker (Recommended)

The easiest way to get the backend and database up and running is using Docker Compose.

```bash
# Start the application and database in detached mode
docker-compose up --build -d
```

The backend API will be available at `http://localhost:8080`.
You can view the Swagger UI documentation at `http://localhost:8080/swagger-ui.html`.

To stop the containers:
```bash
docker-compose down
```

### Local Development (Maven)

If you prefer to run the backend natively:

1. Ensure a PostgreSQL instance is running on `localhost:5432`.
2. Update database credentials in `backend/src/main/resources/application.properties` (or export environment variables `MONDAY_DB_URL`, `MONDAY_DB_USERNAME`, `MONDAY_DB_PASSWORD`).
3. Run the application using Maven wrapper or your local Maven installation:

```bash
cd backend
mvn spring-boot:run
```

## API Documentation

When the application is running, the interactive API documentation is automatically generated by Springdoc OpenAPI.

- **Swagger UI**: [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)
- **OpenAPI JSON**: [http://localhost:8080/api-docs](http://localhost:8080/api-docs)

API contracts for all major modules are also documented as Markdown files for offline reference.

## Authentication

Most endpoints require a valid JWT token. 
1. Create a user via `POST /api/v1/auth/register`.
2. Retrieve a token via `POST /api/v1/auth/login`.
3. Pass the token in the HTTP Headers: `Authorization: Bearer <your_token>`.
